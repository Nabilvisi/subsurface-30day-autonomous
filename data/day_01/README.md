# Day 01 data — Volve 15/9-F-1B

The Day-01 application is configured for Equinor's Volve open-data well **15/9-F-1 B**.

## Source
- Original data owner/source: Equinor Volve open data
- Source page: https://www.equinor.com/energy/volve-data-sharing
- Public mirror used by the automated loader: https://github.com/andymcdgeo/spwla_volve/tree/main/15_9-F-1B
- Input LAS: `WLC_PETRO_COMPUTED_INPUT_1.LAS`

## Standardization
The application standardizes the well-log curves to:

| App field | Volve curve |
|---|---|
| DEPTH | DEPTH |
| GR | GR |
| RHOB | RHOB |
| NPHI | NPHI |
| RT | RACEHM |
| CALI | CALI |

`RACEHM` is treated as the Day-01 deep-resistivity curve (`RT`). Rows lacking the five mandatory Day-01 variables are removed before the calculations.
